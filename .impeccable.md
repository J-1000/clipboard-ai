# Impeccable

## Design Context

### Users

clipboard-ai serves developers, researchers, writers, knowledge workers, and
other macOS power users. They work from the keyboard, frequently move text and
code between applications, and want AI transformations without interrupting
their current task. In the menubar, their primary jobs are to understand whether
monitoring is active, run a common action on the current clipboard, inspect a
recent result, copy it, rerun it, and verify the effective privacy/provider
configuration.

### Brand Personality

Quiet, precise, and trustworthy. The interface should create calm confidence:
it is a capable local utility that stays out of the way, makes privacy state
unambiguous, and reports failures plainly. It should feel considered and native,
never whimsical, chatty, futuristic, or sales-oriented.

### Aesthetic Direction

Use a refined, compact, system-adaptive macOS aesthetic. Favor warm graphite
neutrals and reserve a restrained amber accent for active or selected states.
Use native materials only where they communicate menubar/window hierarchy, not
as decorative glass. Respect the system appearance and typography so light and
dark modes, Dynamic Type, increased contrast, and VoiceOver work naturally.

Avoid neon color, purple/blue AI gradients, glow effects, generic dashboard card
grids, oversized icon tiles, excessive rounding, and decorative motion. The
distinctive motif is a narrow amber activity rail that makes monitoring and
execution state readable at a glance without turning privacy-sensitive content
into decoration.

### Design Principles

1. Make monitoring and privacy state visible before action controls.
2. Lead with useful content: recent results and quick actions, then reveal
   configuration details progressively.
3. Use the amber accent sparingly for selection, live activity, and focus;
   never rely on color alone for status.
4. Prefer native macOS controls, keyboard behavior, system typography, and
   semantic colors over custom chrome.
5. Keep feedback immediate and specific, while honoring Reduce Motion and
   avoiding animation that does not explain a state change.
